# Tool List

## Required

- table saw
- track saw or circular saw with straightedge guide
- router with straight bit and flush-trim bit
- drill/driver
- pocket-hole jig if using pocket-hole joinery
- clamps including at least a few `48 in` class clamps
- tape measure
- combination square
- digital calipers
- straightedge
- level
- countersink bit set
- random-orbit sander

## Helpful

- trim router for template work
- transfer punches for mount-hole layout
- feeler gauges for flushness checks
- step drill for wiring and hose pass-throughs
- shop vacuum or extractor for cleanup during fitting

## Consumables

- painter's tape
- pencils and markers for panel labeling
- glue
- screws per [hardware.csv](./hardware.csv)
- sandpaper per [bom.csv](./bom.csv)
