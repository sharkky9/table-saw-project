# Tool List

## Required

- table saw
- track saw or circular saw with straightedge guide
- full-size router with straight bit and flush-trim bit
- drill/driver
- pocket-hole jig if using pocket-hole joinery
- clamps including at least four `48 in` class clamps plus several smaller F-style or parallel clamps
- tape measure
- combination square
- digital calipers
- straightedge
- level
- drill guide or drill press for accurate pivot-hole drilling
- countersink bit set
- random-orbit sander

## Helpful

- trim router for template work
- transfer punches for mount-hole layout
- feeler gauges for flushness checks
- step drill for wiring and hose pass-throughs
- shop vacuum or extractor for cleanup during fitting
- a second person for the rear top-panel glue-up and install

## Consumables

- painter's tape
- pencils and markers for panel labeling
- glue
- screws per [hardware.csv](./hardware.csv)
- sandpaper per [bom.csv](./bom.csv)

## Capability Notes

- a track saw or straightedge-guided circular saw is strongly preferred for the `90 in` top panels
- the router work assumes a guide-capable full-size router, not just a trim router
- pivot-hole drilling is much easier with a drill guide or drill press; do not freehand those holes if you can avoid it
