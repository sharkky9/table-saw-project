# Table-Saw Infeed Support

## Status

This is an optional later package only. It is not part of the core fixed-top bench geometry.

## Concept

- support type: deployable front support
- concept-only footprint when deployed: `28 x 16 in`
- concept location: centered roughly under the saw infeed path

## Rules

- do not change the core carcass or fixed-top layout just to accommodate this package
- do not let it become a new precision-wing or sliding-carriage project
- it may support stock weight, but it is not a saw-alignment datum
- it must fold or store clear of the miter-station bay and operator stance

## Acceptance Target

If built later, the support only needs to make long rips less awkward. It does not need to carry track, stop, or miter-slot alignment duties.
